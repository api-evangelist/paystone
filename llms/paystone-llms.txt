# Paystone — DataCandy API

> Paystone is a Canadian payment processing and customer-engagement company headquartered in London, Ontario. Its public, self-serve, documented developer API is the DataCandy gift-card and loyalty platform: a REST API built on API Platform (Hydra / JSON-LD) served from api.paystone.com, covering clients, merchants, contacts, gift/loyalty/prepaid/promo account types, loyalty and prepaid transactions, rewards, items, member and balance portals, users, and webhooks. All endpoints require a JWT bearer token. Errors are RFC 9457 problem+json. Paystone's core card-acquiring/payment-gateway processing is a merchant product, not a public self-serve API.

## API
- [DataCandy API docs (Swagger UI)](https://api.paystone.com/docs): Interactive documentation for the DataCandy gift & loyalty REST API.
- [OpenAPI 3.1 export](https://api.paystone.com/docs.jsonopenapi): Machine-readable OpenAPI for the DataCandy API (28 paths, 38 operations, 14 resource groups).
